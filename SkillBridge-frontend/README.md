# SkillBridge Frontend (plan B hackathon)

Si l’équipe frontend livre à temps, on utilise **leur** app. Sinon, celle-ci.

## Lancer

```bash
cd SkillBridge-frontend
npm install
npm run dev
```

Ouvre http://localhost:5173
